# 🤖 JARVIS AI

### Personal AI Assistant for Minecraft Server Management

JARVIS AI is a personal, non-commercial artificial intelligence assistant designed to simplify the administration of private Minecraft servers.

The project integrates Discord, Pterodactyl, and local AI models to provide server monitoring, remote management, and troubleshooting assistance.

## 🎮 Current Features

- Minecraft server monitoring through Pterodactyl.
- Remote server management using private Discord commands.
- CPU, RAM, and storage monitoring.
- Minecraft player activity tracking.
- Automatic server shutdown after prolonged inactivity.
- Minecraft log analysis with AI assistance.
- Modpack discovery through Modrinth.
- Modpack version lookup and update monitoring.

## 📦 Planned CurseForge Integration

JARVIS AI aims to integrate with the official CurseForge API to:

- Search for Minecraft modpacks.
- Retrieve modpack versions and compatibility information.
- Monitor available updates.
- Notify the administrator through Discord.
- Request approval before preparing updates.
- Support authorized modpack installations and server backups.

All integrations are intended to respect mod authors' permissions and the terms of the corresponding platforms.

## 🔒 Privacy and Security

JARVIS AI is a personal project intended for private server administration.

Administrative commands are restricted to authorized users.

The project does not publish private server credentials, authentication tokens, Minecraft worlds, or personal server files.
